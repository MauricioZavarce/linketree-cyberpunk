# CYBER::LINKS 🌐
> Linktree estilo Cyberpunk — Perfil, Links, Vídeo e Formulário de Contato

Site de links único e personalizado, com design futurista, animações, efeitos sonoros e formulário de contato funcional integrado com Formspree. Hospedado gratuitamente na Cloudflare Pages.

---

## ✨ Funcionalidades

- 🎨 **Design Cyberpunk** — cores neon, fundo animado, efeitos visuais
- 🔊 **Efeitos Sonoros** — sons ao clicar, abrir menus, passar o mouse e enviar mensagem
- 📂 **Menus Suspensos** — cada botão expande submenu com links
- ✉️ **Formulário de Contato** — integrado com Formspree, mensagens vão direto no seu e-mail
- 📺 **Vídeo embutido** — espaço para vídeo de destaque
- 📱 **Totalmente Responsivo** — funciona em celular e desktop
- ⚡ **Rápido e Leve** — HTML/CSS/JS puro, sem dependências
